# Онлайн-меню ресторана

Полнофункциональное веб-приложение для просмотра меню ресторана с фильтрацией и защищенной панелью администратора для управления категориями и блюдами.

## Стек технологий

- **Frontend**: React, Vite, React Router, Axios, Vanilla CSS
- **Backend**: Node.js, Express, SQLite (better-sqlite3), Multer (загрузка фото), JWT (jsonwebtoken), CORS, dotenv
- **База данных**: SQLite

---

## Структура проекта

```text
├── backend/            # Серверная часть (Express + SQLite)

│   │   ├── App.jsx     # Роутинг приложения
│   │   ├── MenuPage.jsx# Публичная страница онлайн-меню
│   │   ├── DishCard.jsx# Карточка блюда с фото и ценой

```

## Инструкция по установке и запуску

### 1. Запуск Backend

1. Перейдите в папку `backend`:
   ```bash
   cd backend
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Убедитесь, что в папке `backend` создан файл конфигурации `.env` (если его нет, создайте):
   ```env
   PORT=5000
   JWT_SECRET=super_secret_jwt_key_exam_vibe_2026_x89a7f
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=admin123
   ```

4. Запустите сервер:
   ```bash
   node server.js
   ```
   Сервер запустится по адресу: `http://localhost:5000`

---

### 2. Запуск Frontend

1. В отдельном окне терминала перейдите в папку `frontend`:
   ```bash
   cd frontend
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
   Клиентское приложение откроется по адресу: `http://localhost:5173` (или порту, указанному Vite).

## Данные для входа в панель администратора

- **URL страницы входа**: `http://localhost:5173/admin/login` (или переход по ссылке «Вход в админку →» в шапке меню)
- **Логин**: `admin`
- **Пароль**: `admin123`

## Основные возможности

- **Публичное меню**:
  - Адаптивная сетка карточек блюд (мобильные, планшеты, десктоп);
  - Поиск по названию в реальном времени;
  - Фильтрация по категориям;
  - Фильтрация по диапазону цен («от» и «до»);
  - Отображение фото блюд с плейсхолдером при их отсутствии.

- **Админ-панель**:
  - Защищенный доступ по JWT-токену;
  - Управление категориями (создание, редактирование, удаление с контролем внешних ключей);
  - Управление блюдами (создание, редактирование, удаление);
  - Загрузка изображений блюд (`multipart/form-data`) с раздачей через статику `/uploads/`;
  - Клиентская и серверная валидация полей.
